# ConsultationRevamp — Nwafeth Intelligence Platform (planning)

Greenfield planning package for **منصة نوافث لذكاء الجلسات الاستشارية** (Monsha'at Advisory Session Intelligence Platform) — the new, independent replacement for the legacy Read.ai-based advisory-session analytics system.

**Start here:** [`planning/new-advisory-intelligence-platform/00-INDEX.md`](planning/new-advisory-intelligence-platform/00-INDEX.md) — document map, reading orders per audience, owner-approval list, and the implementation start gate.

The package is 24 documents (~16,200 lines): product contract (26 capabilities), data-source contracts, transcript-provider strategy, target architecture, canonical data model, pipelines, analytical methodology, semantic layer, agentic serving, on-demand deep-analysis factory, Groq model strategy, evaluation oracle, security/PDPL, API contracts, Arabic UX spec, operations/DR, migration & parallel run, delivery roadmap, ADR/OD registers, and the Opus 5 implementation handoff (`23-opus-5-implementation-handoff.md`).

Planning only — no production code. Implementation begins per the start gate in `00-INDEX.md` §6.
